# PracticaPOLESTAR

Prototipo de aplicación de escritorio desarrollado con **WPF, C# y XAML** para la marca Polestar, como parte de la asignatura **Interfaces de Usuario** del Grado en Ingeniería Informática en Tecnologías de la Información de la Universidad Miguel Hernández de Elche.

## Descripción

El proyecto consiste en el diseño y desarrollo de una aplicación de escritorio conceptual que permite consultar una selección de vehículos de la marca Polestar.

La aplicación cuenta con una interfaz visual de estilo minimalista y permite navegar entre diferentes secciones, consultar información de los vehículos y probar un formulario de identificación.

Se trata de un prototipo académico. No es una tienda electrónica real ni está conectado a los servicios comerciales de Polestar.

## Funcionalidades principales

- **Inicio:** presentación de la marca, vehículos destacados y un carrusel de campañas conceptuales.
- **Vehículos:** galería con tres modelos: Polestar 2, Polestar 3 y Polestar 4.
- **Fichas de detalle:** consulta de información específica de cada vehículo, incluyendo precio orientativo, potencia, autonomía y aceleración.
- **Mi cuenta:** formulario de identificación con validación de campos, comprobación del formato del correo electrónico y credenciales de demostración.
- **Navegación:** menú común para acceder a las distintas secciones de la aplicación.
- **Animaciones:** efectos visuales en botones, tarjetas, imágenes y transiciones del carrusel.

## Tecnologías utilizadas

- C#
- XAML
- Windows Presentation Foundation (WPF)
- .NET 10 para Windows
- Microsoft Visual Studio y Blend

## Requisitos para ejecutar el proyecto

- Windows.
- .NET 10 SDK con soporte para aplicaciones WPF.
- Visual Studio con la carga de trabajo de desarrollo de escritorio con .NET.

## Cómo ejecutar la aplicación

1. Descargar el repositorio o clonarlo en el equipo.
2. Abrir el archivo `PracticaPOLESTAR.csproj` con Visual Studio.
3. Esperar a que se cargue el proyecto.
4. Ejecutar la aplicación desde Visual Studio.

## Credenciales de demostración

La pantalla de identificación utiliza credenciales locales incluidas en el código fuente. No existe un sistema de autenticación real ni conexión con un servidor.
